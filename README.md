# Data Science Fundamentals Assessment

A Jupyter notebook covering the data science lifecycle, Python basics,
descriptive statistics, data types, best practices and four practical assignments.

## Contents
1. Data science fundamentals (lifecycle, types of analysis, use cases)
2. Python basics (variables, loops, functions, lists, tuples, dicts, sets, file handling)
3. Statistics (mean, median, mode, variance, std, percentiles, probability, correlation)
4. Data types and structures (numerical, categorical, ordinal, datetime, text)
5. Best practices (naming, documentation, reproducibility, responsible interpretation)
6. Assignments (word frequency, outlier detection, pandas data manipulation, ad spend vs revenue)

## How to run
```
pip install numpy pandas jupyter
jupyter notebook Data_Science_Fundamentals_Assessment.ipynb
```
Then choose Run All. A fixed random seed (42) keeps results reproducible.

## Files
- `Data_Science_Fundamentals_Assessment.ipynb`: the notebook
- `Data_Science_Fundamentals_Report.docx`: the written report
